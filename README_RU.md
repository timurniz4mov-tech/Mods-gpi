# Живые цивилизации — стартовый проект

Версия: Minecraft Java 1.20.1  
Загрузчик: Forge 47.2.0  
Java: 17

## Что уже есть
- Каркас Forge-мода.
- Регистрация предмета «Посох путника».
- Русское и английское название предмета.
- Предмет появляется во вкладке «Инструменты и утилиты» в творческом режиме.

## Как запустить
1. Установи JDK 17.
2. Открой папку проекта в IntelliJ IDEA или Eclipse как Gradle-проект.
3. Дождись загрузки Gradle и зависимостей Forge.
4. Запусти Gradle-задачу `runClient` для тестирования.
5. Для сборки мода выполни `gradlew build` (на Windows — `gradlew.bat build`).
6. Готовый JAR появится в `build/libs`.

## Важно
Это стартовый исходный проект, а не готовый большой мод. Для полноценной сборки Gradle должен скачать Forge и зависимости из интернета. Следующим этапом добавим собственных NPC: путешественника, торговца, рабочего и стражника.
